# HW_PROJECT_PO — Парикмахерская (учёт клиентов, прайс-лист, сотрудники, кассовый журнал)

Учебный проект по дисциплине "Управление качеством программного обеспечения" (СибГУТИ).
Вариант 6 (тема согласована с лабораторной работой №1).

## Модули системы
- Учёт клиентов и запись на услуги
- Ведение прайс-листа услуг
- Учёт сотрудников (мастеров)
- Ведение кассового журнала

## Структура проекта
Работа ведётся по итерациям (Sprint 1, Sprint 2...) через GitHub Projects.
Область (Area) каждой задачи указывается меткой: `area:клиенты`, `area:прайс-лист`, `area:сотрудники`, `area:касса`.

## Сборка и тесты
Автоматическая сборка/тесты запускаются через GitHub Actions при каждом push (см. `.github/workflows/`).
